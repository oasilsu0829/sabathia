# 디자인 언어 v1.0

승찬의 개인 앱(자비스 PWA, 캘린더, 프로젝트 장부 등)에 공통으로 쓰는 디자인 규칙.
스위스 타이포그래피 기반 · 바하마 블루 단일 포인트 · 컨택트 맵 시그니처.

> 한 줄 요약: **흑백 표처럼 정렬하고, 파랑은 "평소", 빨강은 "문제"에만 쓴다.**

---

## 1. 원칙

1. **정렬이 곧 장식.** 그림자·둥근 모서리·그라데이션 없이 선과 열 정렬만으로 구조를 만든다.
2. **색은 의미가 있을 때만.** 기본은 흑백. 바하마 블루 = 오늘·활성·진행·다음. 빨강 = 지연·오류. 둘 외의 색은 없다. (예외는 12장 하나)
3. **숫자가 주인공.** 날짜·시간·진행률·개수는 크게, Space Grotesk로.
4. **제목은 명조, 나머지는 고딕.** 명조는 화면 제목과 섹션 제목에만.
5. **시그니처는 컨택트 맵 하나.** 진행률을 표현하는 유일한 그래픽 요소.
6. **모바일 우선, 투사 겸용.** 같은 레이아웃이 검정 바탕 투사 모드로 그대로 뒤집힌다.

### 색 규칙
- 빨강은 **면 + 흰 글자 칩**으로 쓴다. 빨강 글자는 `−1D` 같은 숫자에만.
- 파랑 칩은 **테두리만**(채우지 않음). 채운 파랑은 "오늘" 칸 하나뿐.
- 화면에 빨강이 없으면 문제가 없는 것이다. 빨강을 장식으로 쓰지 않는다.
- 완료는 색이 아니라 `--muted` + 취소선으로 표시한다.

## 4. 선 · 간격 · 모양

- **선은 두 종류뿐**: 굵은 선 `3px` (섹션 머리, 탭바 위, 캘린더 머리), 가는 선 `1px` (행 구분). 투사 모드에선 가는 선도 `2px`.
- **모서리는 전부 0.** 둥근 모서리 없음.
- **그림자 없음.**
- 화면 좌우 여백 `20px`, 섹션 사이 `24px`, 행 위아래 `12px`(장부는 `16px`).
- 터치 영역 최소 `44px`, 탭바 `56px`, 추가 버튼 `56×56`.

## 5. 시그니처: 컨택트 맵

단백질 컨택트 맵에서 가져온 사각 점 격자. **진행률을 표현하는 유일한 그래픽.**

- 크기: 홈 머리 `7×7`(칸 6px), 프로젝트 `6×6`(칸 5–6px), 간격 2px.
- **모양**: 대각선 띠(|i−j| ≤ 1) + 이름에서 해시로 뽑은 접촉점 몇 개(대칭). 같은 이름이면 항상 같은 모양 → 프로젝트 아이덴티콘.
- **채우기**: 진행률만큼 대각선부터 접히듯 채운다(대각선 → 옆 띠 → 먼 접촉점, 위에서 아래로).
- 색: 채워짐 `--accent`(지연 프로젝트는 `--warn`), 미완 접촉점 `--map-pending`, 빈칸 `--map-empty`.
- 홈 머리의 맵 = 오늘 할 일 완료율. 숫자 없이 맵만 둔다.
- 스크린리더용 `role="img"` + `aria-label="80퍼센트 진행"`.

```js
function contactMap(seed, n, pct) {
  let h = 7;
  for (const ch of seed) h = (h * 31 + ch.codePointAt(0)) >>> 0;
  const rnd = () => (h = (h * 1103515245 + 12345) >>> 0) / 4294967296;
  const set = new Set();
  for (let i = 0; i < n; i++) for (let j = 0; j < n; j++)
    if (Math.abs(i - j) <= 1) set.add(i + ',' + j);
  for (let t = 0; t < n; t++) {
    const a = Math.floor(rnd() * n), b = Math.floor(rnd() * n);
    if (Math.abs(a - b) >= 2) { set.add(a + ',' + b); set.add(b + ',' + a); }
  }
  const order = [...set].map(k => k.split(',').map(Number)).sort((p, q) =>
    Math.abs(p[0] - p[1]) - Math.abs(q[0] - q[1]) ||
    Math.min(...p) - Math.min(...q) || p[0] - q[0]);
  const filled = new Set(order.slice(0, Math.round(order.length * pct / 100)).map(c => c.join(',')));
  // 각 칸: filled → accent, set → pending, 그 외 → empty
  return { set, filled };
}
```

## 6. 화면 구조 (모바일 390 기준)

### 공통
- 위 → 아래: 화면 머리 → 내용(세로 스크롤) → 하단 탭바(고정).
- **탭바**: 4칸 균등, 글자만, **가운데 정렬**, 위에 3px 선. 활성 탭은 `--accent` + 800.
- **추가 버튼**: 탭바 바로 위 오른쪽(`right 20px`, 탭바 위 16px), `56×56` 검정 사각 + `+`. 투사 모드는 흰 사각. 목록 끝에 버튼 높이만큼 여백을 둔다.

### 홈
1. `hero-num` 날짜 + 오른쪽에 "10월 / 수요일"(명조) + 오늘 컨택트 맵
2. 주간 줄: 7칸, 위 3px 선, 오늘 칸만 파랑 면
3. **오늘 할 일**: 섹션 머리(명조 + `완료 / 전체`) → 행 목록
4. **프로젝트**: 2열 카드(코드 · 큰 % · 맵 · 이름 · `n / m 단계`)

### 캘린더
- 머리: `page-title` 월 + 연도(Space Grotesk) + 이전/다음 화살표
- 월 그리드 7×5, 각 칸 위 1px 선, 높이 56
  - 오늘: 파랑 면 / 지난 마감: 빨강 면 / 일정: 검정 6px 점 / 다가올 마감: 빨강 6px 점
  - 범례를 그리드 아래에 둔다
- 아래: 선택한 날의 일정 목록 (할 일 행과 같은 형식)

### 장부
- 머리: `page-title` "장부" + 프로젝트 개수(`04`)
- 필터: 전체 · 진행 · 지연 · 완료 (활성은 3px 파랑 밑줄)
- 행: `[맵] [코드 · 명조 이름 · 다음 — … · 지연 칩] [큰 % · n/m 단계 · D-day]`

**정렬 순서: 지연 → 다음 → 대기 → 완료.** (시간순보다 우선)

| 상태 | 시간 열 | 제목 | 상태 칩 |

## 8. 문구

- 프로젝트 코드: `EXP-01`(실험) · `CODE-02`(코드) · `SCH-04`(학교) — 분류-번호.
- 진행률은 **단계 수로 계산**한다: `4 / 5 단계` → 80. 손으로 % 적지 않는다.
- 날짜 `10.28`, 시간 24시간제 `19:00`, 남은 날 `D-12`, 지난 날 `−1D`.
- 짧은 명사형: "보고서 1일 지연", "다음 — CIF 파서 정리". 이모지 없음.

## 12. 예외: Sabathia 홈 아이콘의 앱 고유색

Sabathia 홈(`/`)의 앱 아이콘에만 앱마다 고유색을 쓴다. 앱 화면 안으로 들어가면 2장 규칙(파랑·빨강) 그대로다.

- 아이콘은 앱 이름으로 만든 컨택트 맵 `7×7`(칸 8px, 간격 2px). 같은 이름이면 같은 모양.
- 채워진 칸 = 고유색(그 앱의 오늘 진행률만큼). 아직 안 채워진 접촉점 = 고유색을 바탕과 섞은 옅은 색(라이트 30%, 투사 45%, 반투명이 아니라 섞은 단색). 빈칸 = `--map-empty`.
- 진행률이 없는 도구(사진 PDF)는 모양 전체를 고유색으로 채운다.
- 문제가 있으면(지연 블록, 지난 할 일) 아이콘 오른쪽 위에 **빨강 면 + 흰 숫자** 배지. 빨강은 여기서도 문제에만.
- 고유색은 빨강(지연)과 헷갈리지 않는 색만 고른다. 값은 `public/apps.js` 한곳에 [라이트, 투사] 쌍으로 둔다.

## 13. Sabathia 공통

- 모든 앱 화면 맨 위에 44px 높이 줄: 왼쪽 `SABATHIA`(홈으로 가는 링크), 오른쪽 앱 코드. Space Grotesk 700 12px, 자간 0.06em, 코드는 `--muted`.
- 앱 코드는 8장 형식(분류-번호). `SCH`는 학교에 남겨 두고 일정은 `CAL`.
- 홈에는 독(하단 작업표시줄)을 두지 않는다. 폰 앱은 "앱" 섹션 머리 오른쪽 `폰 앱 06` 링크로 연다.
- 홈 설정은 "앱" 섹션 머리 오른쪽 `설정` 링크로 여는 시트. 화면 모드 자동 · 일반 · 투사(9장)를 고른다. 기기마다 저장(`localStorage sabathia.theme`), 주소의 `?theme=` 가 먼저. 지금은 홈에만 적용되고 각 앱은 자기 설정을 따른다.
- 홈 배치는 화면에 따라 셋: 가로 화면은 큰 날짜 | 시계 · 다음 | D-day → 하루 줄 3칸(수업 · 15577 · 일정) → 앱. 폰은 큰 시계 → 하루 띠 한 줄 → 지금 · 다음 · 지연 → 앱. 패드 세로는 가로 배치에 오늘 할 일 | 다가올 일정 두 칸을 더한다.
- 하루 줄은 06–24시. 지금 시각은 파랑 2px 세로선, 진행 중 블록은 파랑 2px 테두리, 지연 블록은 빨강 칩(좁으면 빨강 면), 끝난 것은 회색.

## 14. 움직임

Emil Kowalski(Sonner·Vaul) 방식. 움직임은 의미를 싣지 않고 "어디서 왔는지"만 보여 준다. 지금은 Sabathia 홈(`public/index.html`)에만 있다.

- **곡선**: 기본 `--ease-out: cubic-bezier(0.23, 1, 0.32, 1)`. 시트(서랍)는 `--ease-drawer: cubic-bezier(0.32, 0.72, 0, 1)`. 브라우저 기본 `ease`·`linear`는 쓰지 않는다.
- **길이**: 누르기 160ms, 화면 안 요소 200–420ms, 시트 열기 460ms · 닫기 280ms(닫기가 더 빠르다). 홈 첫 화면 전체는 1초 안에 끝난다.
- **자주 보는 화면일수록 적게.** 들어오기는 페이지를 처음 열 때 한 번만. 30초마다 다시 그릴 때, 앱에서 뒤로가기로 돌아올 때(bfcache), 창 크기를 바꿀 때는 움직이지 않는다.
- **움직이는 속성**: `transform`, `opacity`, `filter: blur`, `clip-path`만. 크기·위치(`top`, `width`)는 움직이지 않는다.
- **0에서 시작하지 않는다.** 위로 8px + 흐림 4px + 투명에서 시작. 배지는 `scale(0.6)`에서.
- **누르기**: 누를 수 있는 것은 `scale(0.97)`. 마우스가 있는 화면에서만 호버(앱 아이콘 2px 올라감).
- **흐림은 지나가는 순간에만.** 멈춘 화면에 반투명·흐림은 여전히 없다(10장).

| 홈 구역 | 위에서부터 50ms 간격으로 올라옴 |

- **동작 줄이기**(`prefers-reduced-motion`): 이동·흐림·크기 변화를 모두 빼고 투명도만 남긴다. 시트는 미끄러지지 않고 나타난다.
