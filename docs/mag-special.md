1. 특별판 규칙
- 정기 호 번호를 쓰지 않는다. id는 아래 칸의 것(system.md·mag-new.mjs에 특별판 방식이 있으면 그것).
- 도구가 특별판을 모르면 `node scripts/mag-new.mjs <키> --date 2026-11-14 --force`로 뼈대를 만든 뒤 id·제목·index.json 항목을 특별판으로 바꾸고, 항목에 `"special": true`와 제목 '특별판'을 단다.
- 정기 호 차례와 serials.json 연재 회차는 건드리지 않는다. 연재는 싣지 않는다.
- 다음 정기 예약(feedback 11/16 월, Cypher 11/18 수, Drop 11/20 금)이 이 호 때문에 '이미 있음'으로 멈추지 않게 날짜·id가 겹치지 않는지 확인한다.
- 다른 특별판 세션이 같은 index.json을 고칠 수 있다. 병합 전 기본 브랜치를 다시 받아 충돌을 푼다.

2. 지면 (진짜 잡지처럼)
- 표지 · 편집장의 글 · 특집 커버 스토리(8천~1만2천 자) · 데이터 그래픽 · 짧은 글 여러 꼭지 · 편집 노트 · 부록 LP.
- 순서: 편성 → 취재 노트 → 설계도 → 초고 → 데스크 → 편집장 재작성 → 지면.
- 점수 없음. 들은 척 안 함. 가사 인용 안 함. 출처 없는 사실 안 씀. 출처 10곳 이상. 금지어는 바이블대로.

3. 커넥터
- Unsplash: 분위기·사물 사진. 출처는 Unsplash 페이지 주소.
- Adobe: 사진 보정, 글꼴 추천(없으면 mag-photo.py --look).
- Spotify: 부록 곡 확인 → index.json tracks에 uri.
- Melon: 국내 앨범·크레딧·발매일 확인.
- Canva: 표지 시안이 도움이 될 때.
- 사진 4~8장, 캡션에 저작자·라이선스. 인물·공연 사진은 `python3 -I scripts/mag-photos.py search/get`으로 쓸 수 있는 라이선스만. 요청에 사용자 개인 정보를 넣지 않는다.

4. 검사와 발행
- `python3 scripts/mag-issue.py docs/magazine/issues/<id>`
- `node scripts/mag-check.mjs <id>` 오류 0일 때만 발행. 스크린숏으로 표지·커버 첫 쪽·그래픽·마지막 쪽을 직접 본다.
- 브랜치 mag/<id> → 기본 브랜치로 PR → 바로 squash 병합(사용자 허락). 도구 브랜치를 합쳤다면 그 커밋도 함께.
- 두 번 고쳐도 오류가 남으면 '[발행 보류]' PR만 남긴다.

5. 마지막 답 (한국어, 짧게)
호 id · 주제·커버 · 사진 수와 출처 · 쓴 커넥터 · 출처 수 · 지운 사실 수 · 경고 · 확인 못 한 것
