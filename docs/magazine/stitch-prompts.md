# Stitch 프롬프트 — 잡지 지면 템플릿 (v2)

상자·비닐·넘기기·싱글 떼기는 Sabathia가 직접 만든다(시안 https://claude.ai/artifact/4oxx99KrW6jF1G1Z1Q2n83).
Stitch에는 **종이 지면 한 장 한 장의 디자인**만 맡긴다. 웹앱을 만들지 못하게 매 프롬프트 앞에 0번 규칙을 붙인다.

## 0. 규칙 (모든 프롬프트 맨 앞에 붙임)
```
[규칙 — 반드시 지킬 것]
이것은 웹사이트나 앱이 아니다. 인쇄 잡지의 '지면' 한 장을 디자인하는 것이다.
- 화면 하나 = 잡지 한 쪽. 크기는 정확히 가로 600px × 세로 800px(3:4) 고정. 스크롤 없음, 반응형 없음.
- 넣지 말 것: 상단 메뉴, 내비게이션, 탭, 헤더, 푸터, 미니 플레이어, 검색창, 로그인, 프로필, 사이드바, 버튼, 호버 효과, 애니메이션, 자바스크립트.
- 종이 위에 인쇄된 것만: 글, 사진 자리, 선, 박스, 쪽 번호.
- 사진은 회색 사각형에 '[앨범 표지]', '[아티스트 사진]'처럼 적은 자리로만. 외부 이미지 URL 금지.
- 곡·앨범·아티스트 이름을 지어내지 말 것. [앨범 제목], [아티스트], [곡 제목] 같은 빈칸으로.
- 숫자·사실을 지어내지 말 것. 음질(FLAC, 24bit), 한정판, 독점, 팩트체크 100% 같은 문구 금지.
- 실제 잡지·브랜드·회사·인물 이름과 로고 금지(Spotify 포함).
- 한국어 글꼴 필수: 제목·라벨 'Noto Sans KR', 본문 'Noto Serif KR'. 영문 제호는 따로 지정한 글꼴.
- 본문은 16px 이상이 아니라 '인쇄 지면 비율'로: 본문 13~14px, 행간 1.7, 한 줄 28~34자, 바깥 여백 40px 이상.
- 모든 쪽 아래 여백에 작은 쪽 표시줄: 왼쪽 '잡지 이름 · Vol.01', 오른쪽 '코너 이름 · 쪽 번호'.
- 결과는 지면마다 독립된 HTML 하나. 지면끼리 링크 걸지 말 것.
```

## 1. 잡지 설정 (0번 다음에 붙임, 잡지마다 하나)

### Drop
```
[잡지] Drop — 매주 금요일, 그 주 나온 신보를 다루는 보수적이고 깐깐한 평론 잡지. 출판사 드롭 레코드, 편집 고한석.
분위기: 2000년대 일본 서브컬처 잡지. 흰 종이, 분홍(#f59ad6) 큰 제호, 파랑(#2a2fb0) 단색 일러스트 면, 주황(#f08a16) 강조, 흑백 망점 사진. 제호 글꼴 Archivo Black.
점수: 0.0~10.0 큰 숫자(예시 5.8). 8.0 이상만 '필청' 딱지(예시는 단평 한 곳에 8.1 하나만).
```

### feedback
```
[잡지] feedback — 매주 월요일, 밴드 음악을 다루는 낭만적인 에세이 잡지. 출판사 피드백 프레스, 편집 윤서해. 제호는 항상 소문자.
분위기: 1960년대 팝 잡지. 크림 종이(#f4efe6), 검정, 하늘색(#2bb3d9), 둥근 슬래브 세리프 제호(Alfa Slab One), 사진은 원형으로 잘라냄, 빨간 타원 도장.
점수: '볼륨 9 / 11'. 리뷰마다 '이럴 때 들을 것: [장면 한 줄]'.
```

### Cypher
```
[잡지] Cypher — 매주 수요일, 국내와 해외 힙합을 같은 무게로 다루는 분석적인 평론 잡지. 출판사 사이퍼 미디어, 편집 박지후.
분위기: 크림 종이, 빨강(#b0201e), 검정, 망점(하프톤) 사진, 똑바로 선 굵은 산세리프 제호(Archivo Black, 기울이지 말 것). 빨간 띠, 바코드.
점수: 별 5개, 반 개 단위(예시 ★★★★☆ 4.0). 리뷰 본문 소제목 '가사와 주제 / 랩 / 프로덕션 / 총평'.
표기: 앨범은 [대괄호], 곡은 '작은따옴표'.
```

### 33⅓
```
[잡지] 33⅓ — 매달 1일, '나의' 지난달 청취 기록만으로 만드는 차트 잡지. 출판사 사바시아 출판, 필자 '차트 데스크'.
분위기: 1990년대 영국 문화잡지. 빨강(#d62718), 남색(#1f2a8a), 크림, 굵은 기하학 산세리프 제호(Jost 900), 듀오톤 사진, 표처럼 반듯한 숫자.
점수 없음. 순위, ▲▼(초록·빨강), NEW, 재생 횟수, '기록 [n]일치'.
```

## 2. 지면 (0번 + 1번 다음에 붙임. 한 번에 한 지면)

### 2-1. 차례
```
[지면] 차례 (1쪽).
- 위: 작은 라벨 '차례', 잡지 이름 + 호 번호 크게, 날짜·출판사·편집자 한 줄
- 목록 6줄: 큰 쪽 번호 | 코너 이름 + 아래 작은 회색 글(기사 제목·필자·점수)
- 오른쪽 아래 작게 이번 호 표지 축소 자리(3:4 회색 사각형)
```

### 2-2. 리뷰 첫 쪽
```
[지면] 메인 리뷰 첫 쪽.
- 작은 라벨 '이번 주 리뷰', 큰 제목 '[아티스트] — [앨범 제목]', 필자 이름
- [앨범 표지] 정사각 자리(지면 폭의 45%), 옆에 아주 큰 점수
- 팩트 표 4줄: 발매 / 레이블 / 프로듀서 / 길이·곡 수
- 본문 첫 문단 약 300자 (첫 글자를 크게 하는 드롭캡)
```

### 2-3. 리뷰 이어지는 쪽
```
[지면] 리뷰 이어지는 쪽. 본문만 길게.
- 본문 두 문단(약 650자), 1단
- 중간에 크게 뽑은 한 문장(풀쿼트), 위에 잡지 색 굵은 선
- 사진·박스 없음. 글을 편하게 읽는 쪽.
```

### 2-4. 리뷰 마지막 쪽
```
[지면] 리뷰 마지막 쪽.
- 본문 마지막 문단(약 250자, 판정 문장)
- '반론' 박스: 다른 시각 한 문단(약 120자)
- '점수 근거' 박스: 기준 5개 가로 막대 + 숫자(잡지 기준표대로)
- '트랙 메모': 곡 번호 · [곡 제목] · 한 줄 메모, 4줄
```

### 2-5. 단평
```
[지면] 단평 모음.
- 라벨 '단평'
- 단평 4개를 세로로(또는 2×2): [아티스트] — [앨범 제목] · 점수, 본문 약 200자, 작은 [앨범 표지] 자리
- 사이에 가는 선
```

### 2-6. 코너 쪽 (잡지마다 다름)
```
[지면] 코너 쪽 — 아래 중 이 잡지 것 하나.
- Drop '원본을 들어라': 큰 [옛 앨범 표지] 자리, '[아티스트] — [앨범 제목] (연도)', 왜 이 판이 원본인지 본문 약 400자
- feedback '이 판과 어울리는 밤': 위에 시간·날씨·장소 세 칸, 장면 글 약 400자, 곡 세 개 목록
- Cypher '피처링 지도': 사람 원 8개를 선으로 이은 관계도(원 안 '[이름]'), 옆 해설 약 250자
- 33⅓ '이달의 차트': TOP 20 표(순위·변동·[곡]·[아티스트]·재생·개월), 1위는 위에 크게
```

### 2-7. 출처와 편집 노트
```
[지면] 출처와 편집 노트.
- 라벨, 제목 '이 호에 대해'
- 출처 목록 6줄: [매체] · [글 제목] · [날짜]
- '편집 노트' 박스: 출처 [n]곳 / 확인한 사실 [n]개 / 검수에서 지운 문장 [n]개 / 이번 주 실망 [없음 또는 앨범]
- '판권' 박스: 잡지 · 발행 주기 · 출판사 · 편집자
- 차분한 작은 글자, 잡지 색은 선에만
```

### 2-8. 부록 싱글 쪽 (배경만)
```
[지면] 마지막 쪽 '부록 · 이 호의 노래'의 '종이'만.
- 위: 제목 '부록 · 이 호의 노래', 오른쪽 작게 쪽 번호
- 나머지는 비워 둘 것(앱이 그 위에 비닐에 싼 싱글 5장을 테이프로 붙인다).
- 종이 질감, 잡지 색 얇은 선 하나, 아래에 작은 판권 한 줄 정도만.
```

## 3. 표지 (선택)
```
[지면] 표지(600×800). 제호 크게, 호 번호·날짜·출판사, 커버 문구 자리 3줄, 큰 [아티스트 사진] 자리, '부록 싱글 [n]장 수록', 바코드.
참고 이미지를 첨부하면 그 구성만 참고(로고·상표는 따라 하지 말 것).
```

## 4. 이상하게 나왔을 때
```
웹앱처럼 만들었다. 다시: 메뉴·헤더·푸터·플레이어·버튼·검색·호버·스크립트를 전부 지우고, 600×800 고정 크기의 인쇄 지면 한 장만 남겨. 지어낸 곡·아티스트·숫자·음질 문구도 빈칸([곡 제목] 등)으로 바꿔.
```
