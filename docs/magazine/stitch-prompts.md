# Stitch 프롬프트 — 잡지 표지와 지면 템플릿

순서: 공통 → 표지 4종 → 지면 템플릿 → 잡지별 변형.
표지를 만들 때 참고 이미지 5장(Supreme 잡지 표지, rave, THE FACE, Quick Japan, NIGO 진 페이지)을 같이 첨부한다.
실제 로고·상표는 쓰지 말라고 매번 적어 두었다.

---

## 0. 공통 (맨 처음 한 번)

```
Spotify 음악 플레이어 웹앱 안의 "음악 잡지" 기능을 디자인해줘. 잡지 4종이 있고, 각 잡지는 실제 종이 잡지처럼 표지 + 안쪽 지면 + 마지막 쪽 부록으로 되어 있다.
기기: 아이패드 가로(1194x834, 두 쪽 펼침)와 안드로이드 폰 세로(390x844, 한 쪽씩).
지면 비율은 3:4(세로). 글자는 한국어, 제호와 일부 표제는 영문.
기사는 길고 깊은 평론이다(한 편 2,000~3,500자). 긴 글을 편하게 읽을 수 있는 본문 조판이 가장 중요하다: 본문 16~17px, 한 줄 35~40자, 넉넉한 행간, 2단 칼럼은 아이패드에서만.
사진 자리에는 Spotify 앨범 표지(정사각형)와 아티스트 사진(세로)이 들어간다. 잡지마다 사진 처리 방식이 다르다(듀오톤, 망점, 흑백, 원형 어안).
실제 잡지·브랜드의 이름, 로고, 상표는 쓰지 말 것. 첨부한 참고 이미지는 구성과 분위기만 참고할 것.

잡지 4종:
1. Drop — 금요일 신곡, 출판사 드롭 레코드. 성격: 깐깐하고 보수적인 평론가의 점수 리뷰(0.0~10.0, 8.0 이상 '필청').
2. feedback — 월요일 밴드, 출판사 피드백 프레스. 성격: 낭만적인 밴드 에세이(점수 '볼륨 n/11', '이럴 때 들을 것' 한 줄).
3. Cypher — 수요일 힙합, 출판사 사이퍼 미디어. 성격: 분석적인 힙합 웹진 평론(별 5개, 반 개 단위, 항목별 평가).
4. 33⅓ — 월간, 출판사 사바시아 출판. 성격: 내 청취 기록으로 만든 차트 잡지(순위, ▲▼, NEW).
```

## 1. 표지 4종

### 33⅓ (참고: THE FACE)
```
잡지 '33⅓' 표지(3:4). 첨부 이미지 중 THE FACE 표지의 구성을 참고하되 국기는 쓰지 말고 빨강·남색·크림색의 굵은 방사형 사선 배경으로.
- 맨 위 화면 폭을 꽉 채우는 굵은 기하학 산세리프 제호 "33⅓", 옆에 작게 "월간"
- 오른쪽 위 작은 글자: "No.01 · 2026년 11월호 · 사바시아 출판"
- 가운데: 이달 가장 많이 들은 아티스트 사진(듀오톤 처리), 제호 아래로 겹침
- 사진 위를 비스듬히 가로지르는 큰 커버 문구: "[아티스트]: 이달 [n]번 돌았다" (흰 글자, 검은 그림자)
- 오른쪽 세로 기사 제목 3개(노랑): "아티스트 TOP 20", "언제 듣나", "편집부 vs 나"
- 오른쪽 아래: "부록: 이달의 싱글 [n]장"
- 왼쪽 아래 작은 바코드
```

### feedback (참고: rave)
```
잡지 'feedback' 표지(3:4). 첨부 이미지 중 rave 표지의 구성을 참고.
- 위쪽 크림색 면에 아주 큰 소문자 슬래브 세리프 제호 "feedback", 글자가 화면 밖으로 살짝 넘침. 크림색 면의 아래 가장자리는 둥근 곡선
- 제호 오른쪽 아래 하늘색 작은 글자: "11월 16일 월요일 · VOL.01"
- 검정 바탕 위 커다란 원형 사진(어안 렌즈로 찍은 밴드 사진, 원 밖은 검정)
- 원 위에 비스듬히 굵은 응축 산세리프 커버 문구: "이번 주 밴드 신보 / [앨범 제목] / 이럴 때 들을 것: 막차 놓친 밤"
- 오른쪽 아래 빨간 테두리 타원 도장: "독점! 부록 싱글 [n]장"
- 왼쪽 아래 흰 곡선 두 줄 장식
```

### Cypher (참고: Supreme 잡지 표지)
```
잡지 'Cypher' 표지(3:4). 첨부 이미지 중 빨간 상자 제호 표지의 구성을 참고하되 로고 글꼴(기울어진 Futura)은 쓰지 말고 똑바로 선 굵은 산세리프로.
- 왼쪽 위 빨간 상자 안에 흰 제호 "Cypher"
- 화면 대부분: 망점(하프톤) 처리한 아티스트 사진, 크림색 종이 질감
- 오른쪽 위 작은 글자: "수요일 힙합 주간 · 사이퍼 미디어"
- 오른쪽 아래 빨간 탭: 기울인 굵은 글자 "VOL.01   11.18"
- 맨 아래 빨간 띠: 왼쪽 바코드, 오른쪽 기울인 작은 대문자 설명문 두 줄 "이번 주 앨범 리뷰 [앨범 제목] — [아티스트] ★★★★ · 피처링 지도 · 샘플 추적 · 부록 싱글 [n]장"
```

### Drop (참고: Quick Japan)
```
잡지 'Drop' 표지(3:4). 첨부 이미지 중 Quick Japan 표지의 구성을 참고.
- 흰 바탕, 위쪽에 큰 분홍 제호 "Drop", 그 아래 작게 "드롭 · 금요일 신곡", 오른쪽 위 작은 영문 "New releases, every Friday"
- 파란 단색 일러스트(얼굴 옆모습 여러 개)와 흑백 망점 아티스트 사진을 겹친 콜라주
- 오른쪽에 아주 큰 분홍 세로쓰기 아티스트 이름, 왼쪽에 검정 세로쓰기 앨범 제목
- 분홍 원 배지 "Vol. 01"
- 주황색 큰 글자 "부록 싱글 [n]장 수록", 그 위 검정 작은 글자 "이번 주 필청 [앨범 제목] 8.1"
- 왼쪽 아래 작은 기사 목록: "단평 6", "원본을 들어라", "이번 주 실망"
```

## 2. 지면 템플릿 (잡지 공통 틀, 잡지 색만 바뀜)

### 2-1. 차례
```
잡지 안쪽 첫 쪽 '차례'. 잡지 Drop 기준, 색과 글꼴은 Drop 표지에 맞춰.
- 큰 '차례' 제목, 호 번호와 날짜
- 기사 목록: 쪽 번호(크게) + 코너 이름 + 기사 제목 + 평론가 이름 + 점수(있으면)
  예: 4 이번 주 리뷰 · [앨범] · 고한석 · 5.8 / 10 단평 6 / 16 원본을 들어라 / 20 이번 주 실망 / 24 부록 싱글
- 오른쪽에 이번 호 표지 축소본
- 맨 아래 '편집 노트' 한 줄: "이번 호 출처 21곳 · 검수에서 지운 문장 5개"
```

### 2-2. 메인 리뷰 (두 쪽 펼침)
```
잡지 메인 리뷰 펼침면(아이패드 가로 두 쪽, 폰은 세로로 이어짐).
왼쪽 쪽:
- 코너 이름 "이번 주 리뷰", 큰 제목(아티스트 — 앨범), 평론가 이름
- 큰 앨범 표지
- 점수 박스: 큰 숫자 점수 + 기준별 작은 막대 5개(완결성·곡·소리·절제·오래 남을까) + '점수 근거' 펼치기
- 팩트 박스: 발매일, 레이블, 프로듀서, 길이·곡 수
오른쪽 쪽:
- 리드 문단(본문보다 크게)
- 긴 본문(2단, 사이에 크게 뽑은 풀쿼트 한 줄)
- '반론' 박스: 다른 시각 한 문단
- 트랙별 메모: 곡 번호, 곡 이름, 한 줄 메모, 재생 버튼
- 맨 아래 작은 출처 목록(매체명·제목, 링크)
- 오른쪽 위 '이 앨범 재생'과 '크레이트에 담기' 버튼
```

### 2-3. 단평 모음
```
단평 6편이 한 쪽에 들어가는 지면.
- 2열 격자(폰은 1열). 칸마다: 앨범 표지(작게), 아티스트 — 앨범, 점수, 250~400자 본문, 재생 버튼
- 점수가 8.0 이상이면 '필청' 딱지, 5.0 미만이면 '이번 주 실망' 표시
- 칸 높이가 달라도 정돈되게(벽돌 쌓기 배치)
```

### 2-4. 커버 스토리 (긴 기사)
```
3,000자 커버 스토리 지면(여러 쪽).
- 첫 쪽: 화면 가득 사진 + 큰 제목 + 부제 + 평론가
- 다음 쪽부터: 본문 2단, 중간 소제목, 아티스트 발언 인용(한 문장, 출처 표시), 큰 풀쿼트, 연표 박스(결성 → 앨범들 → 이번 판)
- 마지막에 '이 판과 어울리는 밤' 상자: 시간·날씨·장소 + 곡 세 개
```

### 2-5. 차트 (33⅓)
```
월간 차트 지면.
- '이달의 차트 TOP 20' 표: 순위(크게), 변동(▲ 초록, ▼ 빨강, NEW 남색), 곡, 아티스트, 재생 수, 차트 개월 수, 작은 앨범 표지
- 1위는 맨 위에 크게: 표지, 곡 이름, 재생 수, 한 문단 기사
- 오른쪽 기사 칸: '큰 변동 3건'
- 아래: 장르 비율 막대(지난달 vs 이번 달), 요일×시간대 청취 히트맵(7x24 칸)
- 기록이 모자라면 표 위에 '기록 n일치' 표시
```

### 2-6. 피처링 지도 (Cypher)
```
힙합 잡지의 '피처링 지도' 지면.
- 이번 주 앨범들의 아티스트를 점(사진 원)으로, 같이 작업한 관계를 선으로 이은 관계도
- 여러 앨범에 겹쳐 나온 사람은 크게, 빨간 테두리
- 오른쪽 해설 칸: 겹친 사람 2~3명에 대한 짧은 글
- 아래 '샘플 추적' 띠: 새 곡 ↔ 원곡 짝 3개(두 표지 사이 화살표, 둘 다 재생 버튼)
```

### 2-7. 마지막 쪽 부록 싱글 (참고: NIGO 진 페이지)
```
잡지 마지막 쪽 '부록: 이 호의 노래'. 첨부 이미지 중 NIGO 진 페이지 구성을 참고.
- 뒤에 깔린 큰 영문 제목 "SINGLES", 그 위에 겹친 한국어 부제 "이 호의 노래를 떼어 가세요"
- 왼쪽 큰 칸: 작은 7인치 싱글 9~12장 격자. 싱글 하나 = 종이 슬리브 + 가운데 구멍으로 보이는 판(라벨 색 다름) + 번호 + 곡 제목. 지금 재생 중인 싱글은 표시
- 각 싱글 아래 작은 글자 '○쪽 기사'
- 오른쪽 하늘색 세로 칸: 수록곡 목록(번호, 곡, 아티스트, 길이), 'A면 = 곡 · B면 = 앨범', '전체 재생' 버튼, 맨 아래 바코드
- 배경에 옅은 위장 무늬
```

### 2-8. 출처와 편집 노트
```
잡지 맨 끝 '출처와 편집 노트' 쪽.
- 기사별 출처 목록(기사 제목 아래 매체명·글 제목·날짜)
- 편집 노트 상자: 이번 호에 쓴 출처 수, 확인한 사실 수, 검수에서 지운 문장 수, 취재가 모자라 뺀 앨범
- 정정 상자: 지난 호에서 틀린 것과 바로잡은 내용
- 차분한 작은 글자 위주, 표지 색은 테두리에만
```

## 3. 잡지별 변형 (템플릿을 만든 뒤)

```
위에서 만든 지면 템플릿(차례·메인 리뷰·단평·마지막 쪽)을 잡지 4종에 맞게 변형해줘. 구조는 같고 아래만 바꿔.
- 33⅓: 빨강·남색·크림, 굵은 기하학 산세리프, 사진 듀오톤, 점수 대신 순위
- feedback: 검정·크림·하늘색, 큰 슬래브 세리프 제목, 사진을 원으로 잘라냄, 점수 '볼륨 n/11', 리뷰 머리에 '이럴 때 들을 것'
- Cypher: 빨강·크림·검정, 굵은 산세리프, 사진 망점 처리, 별점(반 개), 본문에 '가사와 주제 / 랩 / 프로덕션 / 총평' 소제목
- Drop: 흰 바탕·분홍·파랑·주황, 큰 분홍 제목, 사진 흑백, 점수 0.0~10.0, '필청' 딱지, 세로쓰기 표제
```

## 4. 함께 필요한 화면 (요소만)

```
잡지 가판대 화면: 위 탭 '지금 재생 · 크레이트 · 잡지'. 이번 주 새 호 4권(안 연 호는 비닐에 싸임, '새 호' 표시), 다음 호 안내 한 줄, 지난 호 가로 목록, 출판사 크레이트 4개로 가는 버튼, 아래 미니 플레이어.
비닐 뜯기 화면: 비닐에 싸인 표지 하나, '가로로 그어서 뜯기' 안내.
출판사 크레이트: 출판사 탭 4개, 나무 상자 뒤에 지난 호 책등, 앞에 부록 싱글, 선택한 항목 정보 카드, 정렬과 찾기.
```
