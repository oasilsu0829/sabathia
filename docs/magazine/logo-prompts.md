# 로고 디자인 프롬프트

Stitch나 이미지 생성 도구에 넣는 프롬프트. 잡지마다 아래 네 가지를 만든다.

| 버전 | 쓰는 곳 | 화면에서 크기 |
|---|---|---|
| ① 제호 | 표지 | 큼 |
| ② 줄임 마크 | 크레이트 앞판 스텐실, 책등 | 중간 |
| ③ 작은 아이콘 | 가판대, 알림 | 32px |
| ④ 출판사 각인 | 판권 쪽, 부록 쪽 하단 | 작음 |

로고는 각 잡지 바이블(`mags/*.md`)의 이름 뜻과 철학에서 나온다.

## 공통 (맨 앞에 붙임)
```
음악 잡지 로고를 디자인해줘. 결과물은 흰 바탕 위 단색(검정) 버전과, 잡지 대표색 버전 두 가지.
다음 4가지를 한 장에 나란히: ① 표지용 제호(가로로 긴 워드마크) ② 줄임 마크(정사각형, 나무 상자에 스텐실로 찍어도 읽히게 단순하게) ③ 32px에서도 알아보는 작은 아이콘 ④ 출판사 각인(작은 글자 로고).
실제 존재하는 잡지·브랜드·음반사 로고와 닮으면 안 된다. 특히 빨간 상자 안 흰 기울어진 글자, 원형 레코드 레이블 흉내, 유명 잡지 제호 글꼴은 피할 것.
선이 너무 가늘거나 그라데이션이 있으면 안 된다(작게 써도, 스텐실로 찍어도 살아야 함).
```

## Drop (드롭 레코드)
```
잡지 이름: Drop. 매주 금요일 신보를 걸러내는 깐깐하고 보수적인 평론 잡지.
이름의 뜻: 신보가 떨어지는 날 / 바늘을 판 위에 내려놓는 순간 / 걸러내는 일.
① 제호: 굵고 묵직한 산세리프 'Drop'. 'o' 안에 바늘이 내려앉는 점 하나, 또는 'p'의 내림 획이 바늘처럼 판 위에 닿는 형태. 장식 없이 단단하게.
② 줄임 마크: 'D' 하나 위에 작은 점(바늘 끝). 정사각형 안에.
③ 아이콘: 원(판) 위에 짧은 사선(바늘) 하나.
④ 출판사 각인: '드롭 레코드' 작은 글자 + 점 하나.
분위기: 오래된 레코드 가게 도장, 엄격함, 절제. 대표색 분홍(#f59ad6)과 파랑(#2a2fb0), 단색 버전은 검정.
```

## feedback (피드백 프레스)
```
잡지 이름: feedback(항상 소문자). 낭만적인 밴드 음악 에세이 잡지, 매주 월요일.
이름의 뜻: 앰프 앞 기타의 울림, 소리가 돌아와 다시 소리를 만드는 것. 소문자는 가까이서 말한다는 뜻.
① 제호: 둥근 슬래브 세리프 소문자 'feedback'. 'ee' 두 글자가 서로 겹치며 울림처럼 번지는 형태(겹친 부분만 다른 색), 또는 마지막 'k' 뒤로 짧은 물결선 세 개.
② 줄임 마크: 소문자 'fb'가 겹쳐 하나의 둥근 형태.
③ 아이콘: 동심원 호 세 개(소리가 돌아오는 모양).
④ 출판사 각인: '피드백 프레스' 작은 글자 + 호 하나.
분위기: 공연장 포스터, 비 오는 밤의 네온, 따뜻함. 대표색 하늘색(#2bb3d9)과 크림(#f4efe6), 단색 버전은 검정.
```

## Cypher (사이퍼 미디어)
```
잡지 이름: Cypher. 분석적인 힙합 평론 잡지, 매주 수요일. 국내와 해외를 같은 무게로 다룸.
이름의 뜻: 래퍼들이 둥글게 서서 차례로 랩을 주고받는 원.
① 제호: 굵고 똑바로 선 산세리프 'Cypher'. 'C'가 원을 이루며 끝이 열려 있고, 그 열린 틈으로 다음 글자가 들어오는 형태(원이 이어지는 느낌). 기울임·스트리트 낙서 글씨는 쓰지 말 것.
② 줄임 마크: 점 여덟 개가 원을 이루고 그중 하나만 꽉 찬 원(지금 차례인 사람).
③ 아이콘: 위 줄임 마크를 더 단순하게(점 여섯 개).
④ 출판사 각인: '사이퍼 미디어' 작은 글자 + 작은 원.
분위기: 진지함, 기록, 웹진. 대표색 빨강(#b0201e), 단색 버전은 검정. 빨간 사각형 안 흰 글자 조합은 쓰지 말 것.
```

## 33⅓ (사바시아 출판)
```
잡지 이름: 33⅓. 나의 한 달 청취 기록으로 만드는 월간 차트 잡지.
이름의 뜻: LP가 1분에 도는 횟수. 한 달 동안 판이 몇 번 돌았는지를 세는 잡지.
① 제호: 굵은 기하학 산세리프 숫자 '33⅓'. 분수 '⅓'의 사선이 턴테이블 톤암처럼 길게 뻗거나, '⅓' 아래 1/3만 채운 작은 원. 숫자는 표 위의 숫자처럼 반듯하게(고정폭 느낌).
② 줄임 마크: 원 하나에 3분의 1만 채운 부채꼴 + 작은 '33'.
③ 아이콘: 3분의 1만 채운 원.
④ 출판사 각인: '사바시아 출판' 작은 글자 + 같은 부채꼴.
분위기: 차트, 기록, 정확함. 대표색 빨강(#d62718)과 남색(#1f2a8a), 단색 버전은 검정.
```

## 출판사 4곳을 한 장에 (크레이트 확인용)
```
위 네 잡지의 ② 줄임 마크만 나무 상자 앞판에 스텐실로 찍은 모습처럼 나란히 보여줘. 단색, 페인트가 살짝 번진 질감. 네 개가 서로 확실히 구별되는지 확인하는 용도.
```
